# 我的教师工作台 · 重设计说明（交 Qoder 开发用）

> 本目录三个 HTML 是可点开的高保真原型，数据为演示占位，交互已可点（tab 切换、事项勾选/新增、任务筛选、考勤弹层、学生签到）。
> 开发时以现有后端接口与 localStorage 结构为准，原型只定视觉与信息架构，不改业务逻辑。

## 文件
- `index.html` —— 登录页（教师端 / 学生端身份切换，分别跳 teacher.html / student.html）
- `teacher.html` —— 教师端：首页 / 工作 / 任务 / 我的 四个 tab
- `student.html` —— 学生端：首页（签到）/ 资料站 / 我的

## 一、设计系统（写进全局 CSS 变量）
**默认主题「紫云」**：主色 `#6D5AE0` / 深 `#5743C7`，主色浅底 `rgba(109,90,224,.10)`；伙伴色蜜柑 `#D98324`（仅「下一节/待提交/提醒」用）；页面底 `#F0EEF7`；卡片 `#FFFFFF`；文字 `#14122B / #3D3A55 / #6F6B88`；状态 成功 `#2C7A62` · 失败 `#C0453C` · 提醒 `#B77A16`。

**六套可切换主题**（`html[data-theme]` 切 token，localStorage `wb-theme` 持久化，教师端/学生端同步；入口在「我的 → 主题配色」）：
| 主题 | data-theme | 主色 | 渐变主卡 | 说明 |
|---|---|---|---|---|
| 紫云（默认） | purple | `#6D5AE0` | `#6D5AE0→#5743C7` | 紫 |
| 青山 | teal | `#176C6B` | `#176C6B→#0F5251` | 青，沉稳 |
| 晴蓝 | blue | `#0A84FF` | `#0A84FF→#0066D6` | 蓝系 |
| 墨绿 | forest | `#2C7A62` | `#2C7A62→#1F5E4B` | 护眼深绿 |
| 暗夜 | dark | `#8B7CFF` | `#5A48C9→#3F328F` | 深色夜间，底 `#17171D` |
| 护眼米 | cream | `#6B8F6F` | `#6B8F6F→#557559` | 米色纸感，底 `#F3EEE2` |

- 圆角三档：卡片 16px / 控件 10px / 胶囊 999px；只有可点的东西用胶囊。
- 字体：系统 sans（PingFang/微软雅黑），数字用 tabular-nums；标题与正文要有字阶差。
- 图标：Phosphor regular 单一字重，全站不混用线宽，不用 emoji。
- 新增主题只需在 `:root` 与 `html[data-theme="x"]` 各补一组 token，主卡渐变用 `--grad-1/--grad-2`。

## 二、信息架构（教师端）
- 底部 4 tab：**首页 / 工作 / 任务 / 我的**（手机底栏；桌面端可还原为左侧栏，分组不变）。
- 首页：问候条 + 搜索 → 今日课程主卡（下一节高亮，可展开全天）→ 今日事项（快速新增、勾选完成）→ 2×2 统计（本周课时/考勤待确认/备课截止/最近笔记）→ 本周课表条。
- 工作：四组宫格，全部旧模块一个不丢——
  - 教学：上课、课表、备课、教材
  - 教务：考勤、监考、出差、维修
  - 记录与学习：笔记、便签、学习、自习任务
  - 学生工具：点名、盲盒、违纪、留言板
- 任务：全部 / 进行中 / 已结束 筛选；卡片带状态条与人数。
- 我的：个人信息、账号安全、工作台设置（主题/布局）、数据备份与恢复、回收站。

## 三、学生端
- 底部 3 tab：首页 / 资料站 / 我的。
- 首页：今日自习任务大卡（进度、已签到人数、倒计时、「立即签到」→ 成功弹层）、我的作业（待提交/已提交/已完成）、班级留言。
- 资料站：教师上传的课件/任务图/作业/教材，网格列表。

## 四、开发注意
1. 原型是 390×844 手机帧；桌面端按旧版侧栏布局适配，配色与卡片语言不变。
2. 所有占位文案（王老师/李同学/时间）替换为真实接口数据；不要保留「设计稿」字样。
3. 弹层为底部 sheet：考勤确认、签到成功；主操作按钮固定在拇指区（底部）。
4. 保留旧版全部功能与本地数据迁移，本次只做视觉与导航分组重做。
